# Bank Groups (RuneLite plugin)

Organize bank items into up to 10 customizable groups with coloured borders and translucent fills. Groups can be used for anything from combat equipment to potions, skilling supplies, teleport items, or any other bank organization system.

## Features

* **Up to 10 groups** — Create separate groups for different types of items.
* **Custom names and colours** — Give each group a name and choose its border colour.
* **Visual highlighting** — Matching items receive a coloured border and translucent fill.
* **Easy editing** — Enable edit mode and click items to add or remove them from the selected group.
* **Safe editing mode** — Normal bank actions are disabled while editing, preventing accidental withdrawals.
* **Mutually exclusive groups** — An item can only belong to one group at a time, keeping borders from overlapping.
* **Placeholder support** — Groups continue to recognize items through their canonical item ID, so highlighting remains associated with an item even when only its placeholder is left in the bank.
* **Persistent settings** — Group names, colours, and item memberships are saved per RuneLite profile.
* **Automatic positioning** — Borders and fills follow items automatically when the bank layout changes.

## Editing Groups

Enable **Edit Mode** from the Bank Groups side panel, then select the group you want to edit.

While edit mode is enabled:

* Left-click an item to add it to the selected group.
* Left-click an item already in the group to remove it.
* Adding an item to a different group automatically removes it from its previous group.
* Normal bank interactions are temporarily disabled to prevent accidental withdrawals.

Disable edit mode when finished to return the bank to normal.

## Group Examples

Groups can be used in many different ways, for example:

* **Melee Gear**
* **Ranged Gear**
* **Magic Gear**
* **Potions**
* **Food**
* **Teleports**
* **Skilling Supplies**
* **Bossing Gear**
* **Quest Items**
* **Frequently Used Items**

The grouping system is flexible and can be customized to suit any bank layout.

## Settings

The plugin provides settings for adjusting the appearance of the highlights, including:

* Fill opacity
* Border width

Additional visual customization may be added in future updates.

## Compatibility

Bank Groups is designed to work with RuneLite's bank interface and automatically tracks item positions as the bank layout changes.

Because RuneLite's internal API can change over time, occasional compatibility updates may be required as RuneLite itself is updated.
